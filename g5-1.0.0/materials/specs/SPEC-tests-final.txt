TITLU:
------
Teste unitare si export OpenAPI pentru modulul materials




DESCRIERE:
----------
Aceasta functionalitate finalizeaza modulul materials prin adaugarea testelor
unitare si pregatirea exportului schemei OpenAPI.

Modulul materials gestioneaza materialele didactice asociate cursurilor.
Functionalitatea existenta include CRUD complet, validari, tratarea duplicatelor,
paginare si filtrare dupa curs.

Aceasta etapa adauga:
- teste unitare folosind pytest si TestClient din FastAPI;
- acoperire pentru creare, citire, actualizare, stergere si cazuri de eroare;
- generarea fisierului materials/openapi.json din aplicatia FastAPI.




MODULE AFECTATE:
----------------
Modul 1: materials
  Modificari:
  - ./tests/test_router_materials.py:
    A fost adaugat un set de teste unitare pentru endpoint-urile modulului.
    Testele folosesc FastAPI TestClient si reseteaza stocarea in memorie
    inaintea fiecarui test.

  - materials/README.md:
    Documentatia modulului a fost completata cu descrierea endpoint-urilor,
    exemple de cereri si raspunsuri, dependentele modulului si instructiuni
    pentru rularea testelor.

  - materials/openapi.json:
    Schema OpenAPI este generata din aplicatia FastAPI si salvata in radacina
    modulului materials.

Modul 2:
  Modificari:
  Nu exista alte module afectate direct.
